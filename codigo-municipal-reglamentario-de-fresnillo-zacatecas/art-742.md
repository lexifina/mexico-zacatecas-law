ARTÍCULO 742.- El color que se aplique a los elementos que compongan la fachada deberá ser acorde con el contexto cromático, a menos que el material tenga acabado aparente. Para llevar a cabo la aplicación o cambio de color se requiere autorización de la Dirección, la que se otorgará bajo las siguientes condiciones:
I.- Se permite el uso de pinturas a la cal;
II.- Queda prohibido el uso de colores brillantes o fosforescentes;
III.- No podrá dividirse las fachadas por medio del color; y
IV.- Se permite el uso de materiales aparentes cuando se presente sin pulir y previo tratamiento para intemperie.
